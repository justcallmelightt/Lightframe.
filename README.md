# ✨ Lightframe.

일상의 작은 불편을 그냥 지나치지 않습니다. 기존 제품이 놓친 차이를 발견하고, 정보보안과 뛰어난 UI·UX를 갖춘 MVP로 구현해 실제 사용자에게도 필요한지 확인합니다.

> 빛나는 수많은 빛, Light가 모여 하나의 Lightframe을 만듭니다.

## Lightframe이 만드는 방식

사업성보다 제품의 이유와 완성도를 먼저 생각합니다. 사소한 불편에서 시작하되, 단지 보기 좋은 결과에 머물지 않고 사용자가 선택할 만한 결정적인 차이를 찾습니다. 그 가설을 안전하고 쓰기 좋은 제품으로 만들고, 실제 사용을 통해 검증합니다.

이 사이트는 그 태도와 과정, 그리고 지금까지 만든 작업을 소개하는 Lightframe의 랜딩 페이지입니다.

## 둘러보기

- **소개** — Lightframe.과 만드는 태도

## 로컬에서 실행

정적 HTML 사이트라 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다. 저장소 루트에서 간단한 HTTP 서버를 실행하세요.

```sh
python3 -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 열면 메인 사이트를, [http://localhost:8000/archive/](http://localhost:8000/archive/)를 열면 아카이브를 볼 수 있습니다. `file://` 대신 HTTP 주소로 실행하면 브라우저의 로컬 파일 제약을 피하고 실제 사이트와 가까운 환경에서 확인할 수 있습니다.

## 기술 및 참고

- 메인 사이트: HTML, CSS, JavaScript
- 스크롤 애니메이션: GSAP, ScrollTrigger, Lenis
- 서체: Pretendard
- GSAP 계열 라이브러리와 서체는 CDN에서 불러오므로 전체 모션과 글꼴을 확인하려면 인터넷 연결이 필요합니다.

데스크톱 Chrome을 우선 확인 환경으로 삼고, 다른 브라우저와 화면 크기에서도 동작을 점검하는 것을 권장합니다. 운영체제의 모션 줄이기 설정도 반영합니다.
